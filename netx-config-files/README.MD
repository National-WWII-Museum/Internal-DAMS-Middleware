These are files that live inside NetX. This is a copy of those files for refrence.

# syncedMetadata.xml
`filepath: netx\config\`

Tells NetX what fields to migrate from the DB (emustaging) and into netx.
It is set up to search Netx for matchin IRN. If found add data from the listed fields.

# autotask.xml
`filepath: netx\config\`

This is where you set up the time for NetX to run the daily syinc task
